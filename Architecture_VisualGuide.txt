CODE EXECUTION FLOW DIAGRAM
════════════════════════════════════════════════════════════════════════════════

Page Load
   │
   ├─→ HTML renders (buttons, layout)
   │
   ├─→ JavaScript loads (functions defined)
   │
   └─→ Run Initialization Code:

       loadMuseumData()
       │
       ├─→ Fetch ./data/Animals.json → MUSEUM_DATA.BotswanaAnimals
       ├─→ Fetch ./data/Birds.json → MUSEUM_DATA.ComprehensiveGuide...
       ├─→ Fetch ./data/Traditions.json → MUSEUM_DATA.BotswaraTraditional
       ├─→ ... (repeat for all 24 files)
       │
       └─→ When all loaded:
           │
           └─→ populateAppData()
               │
               ├─→ populateCultures() 
               │   └─ Create CULTURES[] and CULTURE_SUB[]
               │
               ├─→ populateArtifacts()
               │   └─ Create ARTIFACTS[] with collections
               │
               ├─→ populateGames()
               │   └─ Create GAMES[] with trivia questions
               │
               └─→ populateMuseumInfo()
                   └─ Update MUSEUM_INFO object
       
       showTab('about') → Render ABOUT tab with data
       updateNavHighlight() → Highlight nav button
